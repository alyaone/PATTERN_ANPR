🚘 PATTERN ANPR Project

**Automatic Number Plate Recognition (ANPR)** merupakan project akhir matakuliah Pengenalan Pola yang dibuat untuk mendeteksi dan mengenali nomor kendaraan dari sebuah citra.

Project ini menggabungkan dua metode utama, yaitu YOLOv8 dan OCR. YOLOv8 digunakan untuk menemukan lokasi plat nomor pada gambar, kemudian hasil deteksi tersebut diproses dan diberikan ke OCR untuk membaca karakter pada plat. Jadi, keduanya saling melengkapi: **YOLO untuk menemukan platnya, OCR untuk membaca isinya.** 🤝

## 🔍 Method
📷 Input Image - 🎯 YOLOv8 Detection - ✂️ License Plate Cropping - 🖼️ Image Preprocessing - 🔤 OCR -🚘 Recognized Plate Number

## ✨ Features
🎯 Deteksi plat nomor menggunakan YOLOv8
✂️ Cropping area plat nomor
🖼️ Preprocessing citra
🔤 Pengenalan karakter menggunakan OCR
📊 Evaluasi model
🧪 Prediksi dan demo pada citra baru
